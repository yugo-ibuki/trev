# trev

ローカルの Git リポジトリの差分をターミナルで確認します。

Git と Rust のビルド環境が必要です。リポジトリのルートで次のコマンドを実行するとインストールできます。

```sh
cargo install --path . --locked
```

使い方とバージョンは `trev --help` / `trev --version` で確認できます。

```sh
trev --base origin/main --head HEAD
trev --repo ~/src/project
```

`--repo` の既定は現在のディレクトリ、`--head` の既定は `HEAD` です。`--base` を省略すると、HEAD と異なる既定のリモートブランチ（`origin/HEAD`）、`origin/main`、ローカルの `main` / `master` の順で選び、候補がなければ `HEAD^` と比較します。差分と参照は比較したコミットから読み取ります。

差分と参照先のソース表示では、TypeScript（TSX・MTS・CTS を含む）、Dart、Rust、Python のキーワード・文字列・コメントなどを色分けします。差分の追加・削除は行番号の横の `+`・`-` で区別できます。

| キー | 操作 |
| --- | --- |
| `Tab` | ファイルツリーと差分の間でフォーカスを切り替える |
| `Esc` | 検索を閉じて開く前の画面へ戻る。コード表示では文字選択を解除し、通常の差分表示では左のファイル一覧へ戻る |
| `↑` / `↓` | フォーカス中のペインを移動する |
| `Enter`、`←` / `→` | ファイルツリーのフォルダを開閉する |
| ファイル行で `Enter` | 右ペインを選ぶ |
| `j` / `k` | ファイル一覧では次 / 前の変更ファイル、右ペインではカーソルを下 / 上の行に移動する |
| 右ペインで `h` / `l` | カーソルを左 / 右の文字に移動する |
| 右ペインで `w` / `b` / `e` | 次の単語の先頭 / 前の単語の先頭 / 単語の末尾へ移動する |
| 右ペインで `W` / `B` / `E` | 空白で区切ったかたまりを単位に移動する |
| 右ペインで `0` / `^` / `$` | 行頭 / 行頭の空白を除いた最初の文字 / 行末へ移動する |
| 右ペインで `gg` / `G` | 先頭 / 末尾へ移動する。数字を添えると、対応する行番号へ移動する |
| 右ペインで `H` / `M` / `L` | 画面内の上端 / 中央 / 下端へ移動する |
| 右ペインで `Ctrl+D` / `Ctrl+U`、`Ctrl+F` / `Ctrl+B` | 半画面、または1画面ずつ下 / 上へ移動する |
| 右ペインで `f` / `F`、`t` / `T` と文字 | 同じ行で指定した文字の位置、またはその手前へ移動する。小文字は前方、大文字は後方 |
| 右ペインで `;` / `,` | 直前の文字移動を同じ方向 / 逆方向で繰り返す |
| 右ペインで `v` / `V` | 文字単位 / 行単位の選択を始める |
| 選択中に `iw` / `aw`、`iW` / `aW` | 単語や空白で区切ったかたまりを選ぶ。`a` は周囲の空白も含める |
| 選択中に `⌘C` | 選択範囲をクリップボードにコピーする |
| `y` / `yy`、`yiw` / `yaw` / `yiW` / `yaW` | 選択範囲 / 現在の行、または指定した範囲をクリップボードにコピーする |
| 右ペインで `gd` / `gr` | カーソル上の名前の定義 / 使用箇所を探す |
| 右ペインで `gb` | カーソル行を最後に変更したコミットの表示を切り替える |
| `PageUp` / `PageDown` | 差分をページ単位でスクロールする |
| 差分で `ze` / `zE`、左ペインで `e` / `E` | 画面内で最初の省略区間を20行ずつ / すべて表示する |
| `a` | 差分の印を残したまま、ファイル全体と差分だけを切り替える |
| `Space` | 選択中のファイルの確認済みを切り替える |
| `u` | 未確認のファイルだけを表示する |
| `/`、`n` / `N` | 表示中の差分を検索し、次 / 前の一致へ移動する |
| `Ctrl+P`、左ペインで `f` | 全ファイルを開く。`Tab` でパス検索・中身検索を切り替える |
| `r` | 参照元・参照先を開く。`Tab` で方向を切り替え、`Enter` でソースを表示 |
| 右ペインで `s` | 差分やソースの関数名などをその場で選ぶ |
| クリック / `Shift` + クリック | 選択中のコードから定義 / 使用箇所を探す |
| `d` / `Shift+R` | 名前を入力して定義・使用箇所を探す |
| 差分で `C`、左ペインで `b` | 比較するブランチを検索する。`Tab` で base / head を切り替え、`Enter` で選択 |
| 差分画面で `?` / `q` | 操作ヘルプを開く / レビューを閉じる |

上部の「全ファイル」をクリックするか `Ctrl+P` を押すと、比較先の `head` にあるファイルを、変更の有無にかかわらず開けます。「パス」で検索欄が空のときはフォルダツリーを表示します。フォルダやファイルはクリックで開けます。キーボードでは `↑` / `↓` で選び、`Enter` で開きます。

パス検索は入力に合わせて絞り込みます。「中身」は文字列を入力して `Enter` で検索し、結果に対してもう一度 `Enter` で一致した行を開きます。どちらも大文字・小文字を区別しません。

変更のないファイルと差分に表示されていない行は右ペインで開きます。全ファイル検索から開いたソースで `Esc` を押すと、検索を開く前の画面とペインに戻ります。`Tab` で左のファイル一覧へ、`q` または「戻る」で検索結果へ戻れます。中身検索ではバイナリやロックファイルなどを除き、1ファイルにつき20件、全体で最大500件を表示します。

差分に省略された行があるときは、行間の「↑ 20行」「↓ 20行」をクリックして周囲を広げられます。「全○行を表示」をクリックすると、その区間をまとめて開きます。「ファイル全体」で先頭から末尾まで表示し、「差分だけ」で元の展開状態に戻ります。

ファイルや結果の行、検索・参照方向・比較対象のタブ、確認マーク、検索ボタン、戻るボタンはクリックで操作できます。ファイル一覧やソースなどはホイールで移動できます。検索語はキーボードで入力します。

起動時は左のファイル一覧を操作します。ファイルを選択すると、右ペインのコード上にカーソルが出ます。右ペインをクリックするか `Tab` / `Enter` で切り替えると、コードを操作できます。`3w` のように数字を添えると移動を繰り返します。差分で `42G` を押した場合は、表示中のコードから指定行に最も近い行へ移動します。ファイル全体を表示すると省略されていた行にも移動できます。

`v` または `V` を押してから移動すると、カーソルに合わせて選択範囲が変わります。`⌘C` または `y` でクリップボードにコピーし、選択範囲の先頭へ戻ります。複数行を選んだ場合は改行も含まれます。`Esc` で選択を解除し、通常時の `Esc` で左のファイル一覧へ戻ります。

端末が `⌘C` を端末側のコピーに使っている場合は、`y` で選択範囲をコピーできます。

関数名や型名にカーソルを置いて `gd` または `gr` を押すと、定義または使用箇所をモーダルで検索します。選択中の右ペインでは、名前をクリックすると定義、`Shift` を押しながらクリックすると使用箇所を検索できます。

`gb` または上部の「行の履歴」で行の履歴を表示します。画面下部に、カーソル行を最後に変えた人、変更時期、コミットの件名と短いIDが表示されます。追加行や変更周辺の行は比較先、削除行は差分の旧側の履歴を参照します。全ファイル検索の結果や定義・使用箇所から開いたソースでも使えます。

キーボードでは `s` を押して、表示中のコードから関数名や型名を選べます。`↑` / `↓` で行を移動し、`←` / `→` で行内の名前を選びます。`Enter` または `d` で定義を、`Shift+R` で使用箇所を検索します。

定義・使用箇所のモーダルでは、上下キーかクリックで結果を選ぶと、該当行と前後のコードがモーダルの下半分にある「周辺コード」に表示されます。ファイル全体を読むには `Enter` または「開く」を使います。開いたソースから `Esc` で検索結果に戻り、もう一度 `Esc` で元の表示に戻ります。

差分やソースで直接 `d` / `Shift+R` を押すと、名前を入力して探せます。右ペインで `viw` などを使って語を選んでから開くと、検索語にその語が入ります。`Enter` で検索し、`Tab` で定義と使用箇所を切り替えられます。検索結果からソースを開いても検索語は表示されます。

名前検索はコードと同じコミットを対象にします。差分の削除行から名前を選んだ場合は、旧側を検索します。定義の書き方と識別子の一致から候補を探すため、同名の別の関数や型が候補に含まれることがあります。

確認済みは、`~/.local/share/my-job-tool-cli/` 内の `review-viewed.json` に保存します。同じリポジトリと比較対象では次回起動時に復元され、差分が変わったファイルは未確認に戻ります。

参照一覧は、JavaScript・TypeScript の静的な import・export・require（相対パス・ワークスペース）と、Rust の `mod` および `crate`・`self`・`super` から始まる `use` を表示します。参照元では、JavaScript・TypeScript の静的な読み込みで取り込んだ名前を使う候補行を表示します。使用行を特定できない場合は、読み込み行に「読み込み」と表示します。候補を選ぶと同じコミットの周辺コードを表示します。`Enter` または「開く」で、そのファイルのソースを開きます。

`trev` は対話型のターミナルで実行します。`MY_JOB_TOOL_DATA_DIR` で確認済み履歴の保存先を変更できます。以前の `my-job-tool-cli review` と保存先・ファイル形式・更新ロックを共有するため、同じリポジトリの確認済み履歴を引き継げます。
